\# CSC584 Individual Assignment 1 - Personal Profile Web Application



\## Description

This is a simple web application for creating a personal profile.

The user fills in a form in index.html. The form sends the data to ProfileServlet using POST,

and the servlet passes the data to profile.jsp to display the profile.



Flow: index.html -> ProfileServlet (POST) -> profile.jsp



\## Technologies Used

\- HTML

\- CSS

\- Java Servlet

\- JSP

\- NetBeans IDE 8.2

\- GlassFish Server 4.1.1

\- JDK 1.8



\## How to Run

1\. Download this repository.

2\. Open NetBeans and go to File > Open Project, then choose the PersonalProfile folder.

3\. Make sure the server is set to GlassFish Server 4.1.1.

4\. Right-click the project and click Clean and Build.

5\. Right-click the project and click Run.

6\. The browser will open http://localhost:8080/PersonalProfile/

7\. Fill in the form and click Submit Profile to see the profile page.
